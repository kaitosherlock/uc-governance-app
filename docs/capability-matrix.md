`--source-only` never substitutes for the default runtime check or shape tests. The default command
fails visibly on import errors. An existing source report does not indicate a later runtime run
succeeded: check `evidence_kind` and `observed_at` before citing it.

WS = workspace API, ACC = separately configured account API, SQL = controlled SQL through Statement
Execution, SYS = candidate system-table query through SQL. Application-owned work uses `N/A` because
it is not a Databricks API. U = user token, SP = explicitly delegated app service principal,
ACC-SP = separately configured account service principal. Identity selections are planned policy,
not verified OAuth support; never silently fall back from U to SP. All writes require the plan
lifecycle, authorization, read-back and audit. Every integration additionally requires a configured
identity and verification of its cloud/region/runtime/version limits, even when not repeated below.

`implemented` means existing application code, limited here to three fixture context routes.
`not_implemented` means a declared SDK operation with no application caller, or explicitly identified
application-owned work with no code. `unknown` means method/DTO existence cannot settle operation
semantics or a supported SQL path; the Requires cell says what would settle it. No operation is
marked `unsupported`: missing candidate names do not establish that no documented alternate path
exists. Policy-excluded token operations remain `not_implemented`, with the reason stated, rather
than falsely claiming SDK absence. SQL syntax and system-table names inherited from the local seed
are candidates only, and remain `unknown` pending official documentation.

Model/model-version operations are in 7.11 and also satisfy the inventory requested in 7.1; function
CRUD in 7.1 also covers 7.11. Shared grants and tagging mechanisms apply only after their per-type
support is verified. No universal CRUD, complete group-derived access, or complete dependency graph
is inferred from generic parameters.
